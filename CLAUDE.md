# Working preferences (from the repo owner)

- Subagents are always allowed: for any task, use as many subagents as the work needs, in parallel
  where the parts are independent.
- Pick the model per subagent by difficulty: use `haiku` for basic/simple/mechanical work (small
  edits, lookups, renames, simple checks, straightforward tests), and `opus` only for complex work
  (architecture, tricky algorithms, large features, hard debugging, visual/design polish).
