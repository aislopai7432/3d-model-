Using the 808D-style control
  1. Reference the machine. Select REF POINT and press +Z, +X, +Y (or the Ref. all softkey). AUTO also references automatically if needed.
  2. Pick a program. PROG. MGR lists your programs and the examples. Execute selects one for AUTO and loads its blank; Open edits it in PROGRAM.
  3. Write with cycles. In PROGRAM, the Drilling, Milling and Contour softkeys open input screens with help pictures. OK inserts the cycle call; put the cursor on a call and press Recompile to edit it again.
  4. Set up. OFFSET holds the tool list, wear, work offsets, R variables, setting data and the blank. In JOG, Set WO touches off the active work offset at the tool.
  5. Run. Select AUTO and press CYCLE START. Use SBL for single block, CYCLE STOP to hold, RESET to abort, the feed knob to override and the Simulation slider to go faster. In MDA, type blocks on the Machine screen and press CYCLE START.

The control follows SINUMERIK 808D conventions in Siemens mode (D-number tool offsets, CR=, AC/IC, R parameters, the standard cycles) and accepts ISO dialect programs that start with G291. Machine home is X0 Y0 Z0 with negative travel; work offsets hold the machine position of the part zero.
